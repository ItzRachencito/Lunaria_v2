## 1. INTRODUCCIÓN

### 1.1 Propósito del Manual
Este manual está diseñado para guiarte como usuario del sistema LUNARIA. Aquí encontrarás todas las instrucciones necesarias para navegar por la aplicación, explorar productos, gestionar tus favoritos y realizar compras.

### 1.2 ¿Qué puedes hacer en LUNARIA?
- Explorar el catálogo de productos
- Buscar productos por nombre, marca o categoría
- Ver detalles completos de cada producto
- Agregar productos a tu lista de favoritos
- Ver el historial de tus compras
- Actualizar tu perfil

### 1.3 Roles en el Sistema
| Rol | Descripción |
|-----|-------------|
| **USER** | Cliente con acceso a exploración y compras |
| **ADMIN** | Administrador con acceso completo (no aplica para ti) |

## 11. SOLUCIÓN DE PROBLEMAS

### 11.1 No puedo iniciar sesión
- Verifica tu correo electrónico
- Confirma tu contraseña
- Usa "Olvidaste tu contraseña" si es necesario

### 11.2 No encuentro un producto
- Usa la barra de búsqueda
- Prueba con sinónimos o marcas
- Revisa otras categorías

### 11.3 No puedo agregar al carrito
- Verifica que el producto tenga stock
- Actualiza la página
- Intenta de nuevo

### 11.4 Error al procesar pago
- Verifica tu conexión a Internet
- Confirma los datos de contacto
- Intenta con otro método si está disponible

### 11.5 La app móvil no responde
- Cierra y vuelve a abrir la aplicación
- Actualiza a la última versión
- Libera espacio en tu dispositivo
