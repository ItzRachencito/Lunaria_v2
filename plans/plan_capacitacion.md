# Plan de Capacitación - Proyecto Lunaria

---

## 1. Introducción

Este documento establece el plan de capacitación para usuarios del sistema Lunaria.

---

## 2. Objetivos de Capacitación

- Manipular el sistema de manera eficiente
- Realizar operaciones CRUD de productos
- Gestionar ventas e inventario
- Generar reportes y dashboard
- Resolver problemas básicos

---

## 3. Roles de Usuario

| Rol | Descripción | Capacitación Requerida |
|-----|-------------|----------------------|
| ADMIN | Administrador | Completa |
| USER | Vendedor | Básica |
| CLIENTE | Cliente | Mínima |

---

## 4. Contenido de Capacitación

### 4.1 Módulo 1: Fundamentos (30 min)

- Introducción al sistema
- Navegación y menú principal
- Inicio de sesión
- Cerrar sesión

### 4.2 Módulo 2: Gestión de Productos (1 hora)

- Crear nuevo producto
- Editar producto existente
- Eliminar producto
- Subir imágenes
- Gestionar categorías
- Gestionar marcas

### 4.3 Módulo 3: Proceso de Ventas (45 min)

- Registrar nueva venta
- Seleccionar productos
- Aplicar descuentos
- Elegir método de pago
- Imprimir ticket

### 4.4 Módulo 4: Inventario (30 min)

- Ver stock actual
- Agregar stock
- Registrar movimientos
- Productos con stock bajo

### 4.5 Módulo 5: Reportes y Dashboard (30 min)

- Ver estadísticas del día
- Reporte de ventas
- Productos más vendidos
- Exportar datos
